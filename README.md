# Alura Imersão Engenharia de Dados com IA 🏗️🤖

Repositório de estudos e entregas desenvolvidas durante a Imersão Engenharia de Dados com IA da Alura.

O projeto principal está em [`voebem-analytics-databricks/`](voebem-analytics-databricks/) e implementa um projeto prático baseado em dados reais abertos da aviação brasileira, ANAC (Agência Nacional de Aviação Civil), focando na análise de operações aéreas no Brasil, especialmente no estudo de atrasos de voos, pontualidade, taxas de cancelamento e eficiência das companhias aéreas, utilizando a ferramenta Databricks.

## 📌 Projeto

- [`voebem-analytics-databricks/`](voebem-analytics-databricks/): utiliza dados de voos, aeroportos e operadores aéreos, todos em formato CSV, para praticar o processo completo de ingestão, organização e análise de dados.  
A arquitetura de dados adotada é o modelo medalhão (bronze, silver e gold), que organiza os dados em camadas: bronze para dados brutos, silver para dados tratados e curados, e gold para dados prontos para consumo.
