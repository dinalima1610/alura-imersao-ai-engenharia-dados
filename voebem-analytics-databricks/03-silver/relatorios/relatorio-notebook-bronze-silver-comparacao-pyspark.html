1 Objetivo

Comparação Bronze vs Silver: Análise de Transformações

Este notebook compara as tabelas da camada Bronze (voebem.bronze) com suas versões transformadas na camada Silver (voebem.silver).

Objetivo: Entender quais mudanças foram aplicadas aos dados durante a transformação, incluindo:

  • Mudanças de tipos de dados
  • Padronização de valores
  • Colunas adicionadas ou renomeadas
  • Qualidade dos dados antes e depois

Observação: Todas as consultas são somente leitura (SELECT apenas).

Escopo do relatório: conversão visual do notebook exportado do Databricks, preservando comandos, explicações, resultados tabulares, métricas e conclusões sem alterar a origem.

O notebook compara a camada Bronze com a camada Silver do catálogo voebem, dentro de uma arquitetura medalhão.

# Compara os tipos de dados das colunas da tabela VRA
# Bronze: todos os campos como STRING (regra da camada)
# Silver: tipagem semântica (TIMESTAMP, DATE, INT, etc.)

display(spark.sql("""
    SELECT
        'vra' AS tabela,
        COALESCE(b.column_name, s.column_name) AS coluna,
        b.data_type AS tipo_bronze,
        s.data_type AS tipo_silver,
        CASE
            WHEN b.column_name IS NULL THEN 'NOVA (criada na silver)'
            WHEN s.column_name IS NULL THEN 'REMOVIDA'
            WHEN b.data_type <> s.data_type THEN CONCAT('TIPO MUDOU: ', b.data_type, ' -> ', s.data_type)
            ELSE 'igual'
        END AS observacao
    FROM (
        SELECT column_name, data_type
        FROM voebem.information_schema.columns
        WHERE table_schema = 'bronze' AND table_name = 'vra'
    ) b
    FULL OUTER JOIN (
        SELECT column_name, data_type
        FROM voebem.information_schema.columns
        WHERE table_schema = 'silver' AND table_name = 'vra'
    ) s ON b.column_name = s.column_name
    ORDER BY
        CASE WHEN b.column_name IS NULL THEN 1 ELSE 0 END,
        COALESCE(b.column_name, s.column_name)
"""))

Exibir código completo: Empresas: Silver vs Bronze (nacionais + estrangeiras)
# Compara a tabela Silver empresas (unificada) com as duas tabelas Bronze
# A Silver une empresas_nacionais + empresas_estrangeiras em uma única tabela

display(spark.sql("""
    WITH silver_cols AS (
        SELECT column_name, data_type
        FROM voebem.information_schema.columns
        WHERE table_schema = 'silver' AND table_name = 'empresas'
    ),
    bronze_nac AS (
        SELECT column_name, data_type
        FROM voebem.information_schema.columns
        WHERE table_schema = 'bronze' AND table_name = 'empresas_nacionais'
    ),
    bronze_est AS (
        SELECT column_name, data_type
        FROM voebem.information_schema.columns
        WHERE table_schema = 'bronze' AND table_name = 'empresas_estrangeiras'
    )
    SELECT
        'empresas' AS tabela,
        s.column_name AS coluna_silver,
        s.data_type AS tipo_silver,
        bn.data_type AS tipo_bronze_nacionais,
        be.data_type AS tipo_bronze_estrangeiras,
        CASE
            WHEN bn.column_name IS NULL AND be.column_name IS NULL THEN 'NOVA (criada na silver)'
            WHEN bn.column_name IS NOT NULL AND be.column_name IS NULL THEN 'só em nacionais'
            WHEN bn.column_name IS NULL AND be.column_name IS NOT NULL THEN 'só em estrangeiras'
            ELSE 'herdada de ambas'
        END AS observacao
    FROM silver_cols s
    LEFT JOIN bronze_nac bn ON s.column_name = bn.column_name
    LEFT JOIN bronze_est be ON s.column_name = be.column_name
    ORDER BY s.column_name
"""))

display(spark.sql("""
    SELECT
        'bronze.vra' AS tabela,
        SUM(CASE WHEN partida_real = 'null' THEN 1 ELSE 0 END) AS partida_real_str_null,
        SUM(CASE WHEN partida_real IS NULL THEN 1 ELSE 0 END) AS partida_real_null_real,
        SUM(CASE WHEN chegada_real = 'null' THEN 1 ELSE 0 END) AS chegada_real_str_null,
        SUM(CASE WHEN chegada_real IS NULL THEN 1 ELSE 0 END) AS chegada_real_null_real,

        COUNT(*) AS total_linhas
    FROM voebem.bronze.vra
    UNION ALL
    SELECT
        'silver.vra',
        0,
        SUM(CASE WHEN partida_real IS NULL THEN 1 ELSE 0 END),
        0,
        SUM(CASE WHEN chegada_real IS NULL THEN 1 ELSE 0 END),
        0,
        COUNT(*)
    FROM voebem.silver.vra
"""))

9 Conclusão

4. Resumo das Transformações

Principais mudanças aplicadas na camada Silver:

VRA (Voo Regular Ativo)

  • Tipos de dados: STRING → TIMESTAMP (partida_prevista, partida_real, chegada_prevista, chegada_real)
  • Padronização: String 'null' → NULL real; String 'N/A' → NULL
  • Novas colunas derivadas:
  • partida_prevista_data, partida_prevista_hora (extraídas de partida_prevista)
  • partida_real_data, partida_real_hora (extraídas de partida_real)
  • atraso_partida_min: minutos de atraso na partida
  • atraso_chegada_min: minutos de atraso na chegada
  • minutos_recuperados: diferença entre atraso de partida e chegada
  • Auditoria: _transformado_em (timestamp da transformação)

Aerodromos

  • Tipos de dados: altitude STRING com vírgula → altitude_m DOUBLE
  • Colunas renomeadas para clareza:
  • uf → uf_nome
  • uf_servido → uf_servido_nome
  • latitude → latitude_dms
  • longitude → longitude_dms
  • Auditoria: _transformado_em

Empresas

  • União de tabelas: empresas_nacionais + empresas_estrangeiras → uma única tabela empresas
  • Nova coluna: origem_cadastro (indica se é 'nacional' ou 'estrangeira')
  • Auditoria: _transformado_em

Códigos de Operação

  • Espelho direto: estrutura mantida sem alterações significativas
  • Auditoria: _transformado_em adicionada
