3. Código PySpark de Validação

Python — Célula 1: Importar e carregar

from pyspark.sql.functions import col, sum as _sum, count, avg, round as _round, when, lit

# Carregar a tabela fato_voos da camada Gold
fato_voos = spark.table("voebem.gold.fato_voos")
print(f"Total de registros: {fato_voos.count():,}")

Python — Célula 2: Filtrar e agrupar

# Filtrar voos com avaliação de pontualidade
voos_avaliados = fato_voos.filter(col("partida_pontual").isNotNull())

# Agrupar por companhia e calcular métricas
resultado = (
    voos_avaliados.groupBy("nome_companhia")
    .agg(
        _sum(when(col("partida_pontual") == False, 1).otherwise(0)).alias("voos_atrasados"),
        count("partida_pontual").alias("voos_avaliados"),
        _round(_sum(when(col("partida_pontual") == False, 1).otherwise(0)) * 100.0
            / count("partida_pontual"), 2).alias("pct_atraso"),
        _round(avg(when(col("partida_pontual") == False, col("atraso_partida_min"))), 1).alias("atraso_medio_min")
    )
    .filter(col("voos_atrasados") > 100)
    .orderBy(col("voos_atrasados").desc())
    .limit(10)
)
resultado.show(truncate=False)

Python — Célula 3: Exibir formatado

import pandas as pd

5. Conclusão da Validação

O código PySpark validou de forma independente a resposta do Genie Agent usando a mesma tabela (voebem.gold.fato_voos) e o mesmo critério de atraso (partida_pontual = FALSE). O caminho PySpark percorrido foi:

  1. spark.table() — carregou a tabela Gold
  2. .filter() — selecionou voos com avaliação de pontualidade
  3. .groupBy().agg() — agrupou por companhia e calculou contagem, percentual e média
  4. .orderBy().limit() — ordenou por volume de atrasos e limitou ao top 10
