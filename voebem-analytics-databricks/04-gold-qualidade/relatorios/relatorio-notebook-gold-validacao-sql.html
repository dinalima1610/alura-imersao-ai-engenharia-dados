7 Consulta SQL de validação

A consulta abaixo foi registrada no notebook como validação independente da resposta do Genie Agent.

Exibir ou ocultar consulta SQL completa
SQL 
-- ============================================================================
-- VALIDAÇÃO SQL: Companhias aéreas com maior quantidade de voos atrasados
-- ============================================================================
-- Esta consulta valida de forma independente a resposta do Genie Agent.
-- Critério: partida_pontual = FALSE (atraso de partida > 15 minutos)
-- Filtro: companhias com mais de 100 voos atrasados (remove ruído)
-- ============================================================================

SELECT
  nome_companhia,
  SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) AS voos_atrasados,
  SUM(CASE WHEN partida_pontual IS NOT NULL THEN 1 ELSE 0 END) AS voos_avaliados,
  ROUND(
    SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) * 100.0
    / NULLIF(SUM(CASE WHEN partida_pontual IS NOT NULL THEN 1 ELSE 0 END), 0),
    2
  ) AS pct_atraso,
  ROUND(AVG(CASE WHEN partida_pontual = FALSE THEN atraso_partida_min END), 1) AS atraso_medio_min
FROM voebem.gold.fato_voos
GROUP BY nome_companhia
HAVING SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) > 100
ORDER BY voos_atrasados DESC
LIMIT 10
