Validação SQL — Companhias Aéreas com Maior Quantidade de Voos Atrasados

Objetivo: Validar diretamente nos dados da camada Gold a resposta obtida pelo Genie Agent sobre quais companhias aéreas apresentaram a maior quantidade de voos atrasados no período analisado.

Período dos dados: agosto/2025 a agosto/2026
Tabelas utilizadas: voebem.gold.fato_voos, voebem.gold.dim_aeroporto
Critério de atraso: partida_pontual = FALSE (atraso de partida superior a 15 minutos)

1. Pergunta de Negócio Validada

Quais companhias aéreas apresentaram a maior quantidade de voos atrasados no período analisado?

Foi escolhida para validação porque envolve ranking por contagem — um tipo de resposta que pode ser verificado de forma direta e inequívoca com uma consulta SQL independente.

3. Consulta SQL de Validação

-- VALIDAÇÃO SQL: Companhias aéreas com maior quantidade de voos atrasados
-- Critério: partida_pontual = FALSE (atraso de partida > 15 minutos)

SELECT
  nome_companhia,
  SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) AS voos_atrasados,
  SUM(CASE WHEN partida_pontual IS NOT NULL THEN 1 ELSE 0 END) AS voos_avaliados,
  ROUND(
    SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) * 100.0
    / NULLIF(SUM(CASE WHEN partida_pontual IS NOT NULL THEN 1 ELSE 0 END), 0),
    2
  ) AS pct_atraso,
  ROUND(AVG(CASE WHEN partida_pontual = FALSE THEN atraso_partida_min END), 1) AS atraso_medio_min
FROM voebem.gold.fato_voos
GROUP BY nome_companhia
HAVING SUM(CASE WHEN partida_pontual = FALSE THEN 1 ELSE 0 END) > 100
ORDER BY voos_atrasados DESC
LIMIT 10
