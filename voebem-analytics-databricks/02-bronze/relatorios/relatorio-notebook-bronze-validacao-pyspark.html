📊 Validação da Camada Bronze

Relatório de validação das cinco tabelas da camada Bronze do catálogo voebem. Consultas somente leitura que verificam a ingestão dos dados de aviação civil brasileira (ANAC).

🎯 Objetivo

Este notebook realiza três verificações para cada tabela da camada Bronze:

  • Contagem de registros — COUNT(*) para verificar o volume total ingerido
  • Esquema — colunas, tipos de dados e propriedades via information_schema
  • Amostra — até 10 primeiros registros via SELECT * LIMIT 10

Nenhum dado é inserido, atualizado ou excluído. Todas as operações são somente leitura.

📋 Contexto do Projeto

Pipeline de dados para aviação civil brasileira seguindo arquitetura medallion (Bronze/Silver/Gold). Os dados são provenientes da ANAC (Agência Nacional de Aviação Civil).

Catálogo: voebem
Schema: bronze
Regras da Bronze: todas as colunas como string, nenhuma linha descartada, colunas de auditoria (_arquivo_origem, _ingerido_em)

🗂️ Tabelas Analisadas

aerodromos codigos_operacao empresas_estrangeiras empresas_nacionais vra

VRA = Voo Regular Ativo (dados de voos agendados da ANAC). Fonte: CSVs em /Volumes/voebem/bronze/arquivos/vra/

1️⃣ Verificação 1 — Contagem de Registros (SQL)

Consulta única com UNION ALL sobre as cinco tabelas:

-- Validação 1: total de registros em cada tabela da Bronze
SELECT 'aerodromos' AS tabela, COUNT(*) AS total_linhas 
FROM voebem.bronze.aerodromos
UNION ALL
SELECT 'codigos_operacao' AS tabela, COUNT(*) AS total_linhas 
FROM voebem.bronze.codigos_operacao
UNION ALL
SELECT 'empresas_estrangeiras' AS tabela, COUNT(*) AS total_linhas 
FROM voebem.bronze.empresas_estrangeiras
UNION ALL
SELECT 'empresas_nacionais' AS tabela, COUNT(*) AS total_linhas 
FROM voebem.bronze.empresas_nacionais
UNION ALL
SELECT 'vra' AS tabela, COUNT(*) AS total_linhas 
FROM voebem.bronze.vra
ORDER BY tabela

2️⃣ Verificação 2 — Esquema das Tabelas (SQL)

Lista colunas, tipos de dados e propriedades via information_schema.columns:

SELECT
    table_name   AS tabela,
    column_name  AS coluna,
    data_type    AS tipo,
    is_nullable  AS permite_nulo,
    comment
FROM voebem.information_schema.columns
WHERE table_schema = 'bronze'
  AND table_name IN (
      'aerodromos',
      'codigos_operacao',
      'empresas_estrangeiras',
      'empresas_nacionais',
      'vra'
  )
ORDER BY table_name, ordinal_position
