1 Objetivo

Validar a integridade da ingestão dos dados na camada Bronze do pipeline de aviação civil brasileira (ANAC). O notebook executa três verificações por tabela, sem qualquer modificação nos dados:

  • Contagem de registros — df.count() para confirmar que cada tabela possui dados.
  • Esquema de colunas — inspeção de nomes e tipos via df.schema.
  • Amostra de dados — df.show(10, truncate=False) para visualizar os primeiros registros.
Princípio: Apenas operações de leitura. Nada é inserido, atualizado, excluído ou criado.
2 Contexto do Pipeline

Arquitetura Medalhão

O projeto segue a arquitetura de medalhão (medallion architecture) com três camadas:

Bronze — dados brutos Silver — dados limpos Gold — dados agregados

Regras da Camada Bronze

  • Todas as colunas armazenadas como string, sem descarte de linhas.
  • Colunas de auditoria: _arquivo_origem e _ingerido_em.
  • Ingestão idempotente via mode("overwrite") (full-refresh).
  • CSVs brasileiros: separador ponto e vírgula (;), skipRows=1 (BOM + linha "Atualizado em").
  • Nomes de colunas convertidos de português com espaços para snake_case para compatibilidade Delta.
Catálogo: voebem · Schema: bronze · Fonte: Dados públicos da ANAC (Agência Nacional de Aviação Civil).

4 Código Principal

Script Python executado no notebook, utilizando PySpark DataFrame API:

# =============================================================================
# Validação pós-ingestão da camada Bronze
# Apenas leitura: nada é inserido, atualizado, excluído ou criado.
# Para cada tabela, exibe:
#   1. Quantidade de registros
#   2. Colunas e tipos de dados (esquema)
#   3. Até 10 primeiros registros
# =============================================================================

# Lista das cinco tabelas da camada Bronze a validar
TABELAS_BRONZE = [
    "voebem.bronze.aerodromos",
    "voebem.bronze.codigos_operacao",
    "voebem.bronze.empresas_estrangeiras",
    "voebem.bronze.empresas_nacionais",
    "voebem.bronze.vra",
]

for tabela in TABELAS_BRONZE:
    print("=" * 70)
    print(f"TABELA: {tabela}")
    print("=" * 70)

    # Carrega a tabela como DataFrame (somente leitura)
    df = spark.table(tabela)

    # 1) Quantidade de registros
    total = df.count()
    print(f"\n[1] Total de registros: {total:,}\n")

    # 2) Colunas e tipos de dados
    print("[2] Colunas e tipos de dados:")
    for campo in df.schema:
        print(f"    {campo.name:<30s} -> {campo.dataType.simpleString()}")
    print()

    # 3) Primeiros registros (até 10)
    print("[3] Primeiros registros (máximo 10):")
    df.show(10, truncate=False)
    print()
